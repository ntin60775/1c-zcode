# 1c-zcode — вход для агента

ZCode-плагин контура 1С-разработки: порт 1c-omp с соседней директории.
Статус переноса слоёв и что дальше — docs/migration-map.md.

## Что знать до правки

- **Специфики проектов здесь быть не должно.** Ни имён баз, ни учёток, ни
  объектов, ни путей. Всё зависящее от проекта читается из `v8project.yaml` /
  `v8project.local.yaml` либо живёт в самом проекте отдельным файлом.
- **Хуки — это hooks.json + скрипты, не omp-расширения.** Здесь нет `HookAPI`
  и TS-модулей: событие из семи поддерживаемых, матчер — regex по имени
  инструмента, блок = exit 2 с причиной в stderr, таймауты у `process`-хуков —
  в миллисекундах (`timeoutMs`). После правки гейта — тест + ручной прогон
  stdin → код возврата.
- **Хуки ZCode stateless.** Каждый запуск — новый процесс; состояние сессии
  (флаг сверки doc-гейта, счётчик ретраев) держать внешне по `session_id` из
  входа хука, не в памяти процесса.
- **Имя плагина = имя каталога = `^[a-z0-9][a-z0-9._-]{0,127}$`.** Версия в
  `.zcode-plugin/plugin.json` синхронна записи в `marketplace.json`.
- **Прозу правил omp сюда не копировать как есть.** Слоя `rules/` с TTSR в
  ZCode нет: всегда-загружаемое живёт в AGENTS.md целевого проекта,
  остальное — навыками с честным description (по нему навык и поднимают).

## Проверка перед коммитом

```bash
# 1. Ни одного имени чужого проекта, базы, учётки или объекта.
#    Сами имена — в .forbidden-names.txt (gitignored, одна строка = grep-паттерн):
PAT=$(cat .forbidden-names.txt 2>/dev/null)
[ -z "$PAT" ] && echo 'НЕТ .forbidden-names.txt — заведи его, проверка не выполнена' \
  || (grep -rnE "$PAT" --include='*.md' --include='*.py' --include='*.json' . \
        --exclude-dir=.git --exclude='.forbidden-names.txt' \
      && echo 'НАЙДЕНО — править' || echo 'чисто')

# 2. Гейт жив и логика совпадает с ожиданием
python3 tests/test_unica_source_gate.py
```

## Донор

`../1c-omp` — переносить послойно по docs/migration-map.md. Копируя текст,
переводи механику: `.omp/` → `.zcode/`, `~/.omp/logs` → `~/.zcode/logs`,
блок из `return { block: true }` → `exit 2` + stderr, TS → python3 (stdlib).
