# Каталог kd2-rules — файлы правил обмена «Конвертации данных» 2

Хранение в git файлов правил КД 2: XML правил обмена (`ExchangeRules.xml`),
правил корреспондента (`CorrespondentExchangeRules.xml`) и правил
регистрации (`RegistrationRules.xml`), zip-комплекты для штатной загрузки
через БСП, обёртки обработчиков для синтакс-чекера. Рекомендуемая
компоновка — подкаталог на обмен (пару конфигураций): правила и комплекты
одного обмена не перемешиваются с чужими.

## Правила
- Каталог git-tracked: держать историю правил рядом с кодом проекта;
  сборочные артефакты (`build/`) сюда не класть.
- Файлы пишет сервер kd-rules-mcp (MCP `1c-kd`) по `rules_dir` —
  инструменты `rules_save`/`handlers_export`; путь в станцию прописывает
  `kd_register_project.py` (авто-детект этого каталога) или руками в
  `projects.yaml` станции.
- Каноны построения и проверки правил — скиллы `kd2-rules-build`,
  `kd2-exchange-pitfalls`; сводка канала — скилл `1c-kd-rules`.
- Перед загрузкой в базу-приёмник правила проверяются каналом kd
  (`rules_validate`); zip-комплекты для БСП — именем папки обмена.
