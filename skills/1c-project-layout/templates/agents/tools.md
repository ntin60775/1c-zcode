# Каталог tools — инструменты и конфигурации проекта

Служебные скрипты и конфигурации разработки/тестирования проекта.
Это НЕ вендоренная поставка контура (та живёт в `.zcode/1c/scripts`).

## Правила

- Сюда — узкие скрипты и конфиги конкретного проекта: обвязка запусков,
  исключения синтаксического контроля, генерация данных.
- `tools/mcp` (если есть) — обработка 1c-mcp-toolkit под ОС хоста
  (`MCP_Toolkit_linux.epf` на Linux и т. д.) для 1c-db, в git
  не попадает; доставляет `start_1c_db.sh`.
- Секреты и пароли сюда не класть.
