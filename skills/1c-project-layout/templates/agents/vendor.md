# Каталог vendor — вендоренный внешний код

Внешние зависимости проекта: паки, тулкиты, библиотеки, бинарные
компоненты, вендоренные расширения.

## Правила

- Источник и лицензия каждого вендоренного артефакта фиксируются
  (комментарий/файл рядом или запись в docs).
- Обновление вендоренного — осознанной заменой, не «докачать поверх».
- Тяжёлые артефакты проект может точечно игнорировать в `.gitignore`,
  но сам каталог трекается этим AGENTS.md.
