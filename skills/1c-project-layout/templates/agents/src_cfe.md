# Каталог src/cfe — исходники расширений

XML-выгрузки расширений конфигурации. На каждое расширение — отдельный подкаталог.

## Правила
- Исходники расширений правятся только через Unica (`unica.apply`), не руками.
- Появившееся расширение объявляется source-set'ом типа EXTENSION в `v8project.yaml`.
- Служебные файлы выгрузки не коммитятся.
