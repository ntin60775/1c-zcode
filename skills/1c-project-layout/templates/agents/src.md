# Каталог src — исходники 1С

XML-выгрузки конфигурации и внешних артефактов; тип артефакта — по
подкаталогу (cf/cfe/epf/erf), правила подкаталога — в его AGENTS.md.

## Правила
- Исходники правятся только через Unica (`unica.apply`), не руками.
- Служебные файлы выгрузки (`ConfigDumpInfo.xml`, `DumpFilesIndex.txt`, `.build/`) не коммитятся.
