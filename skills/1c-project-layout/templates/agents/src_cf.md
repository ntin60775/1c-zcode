# Каталог src/cf — исходники конфигурации

XML-выгрузка основной конфигурации (source-set `main`). Источник правды для сборки.

## Правила
- Исходники правятся только через Unica (`unica.apply`), не руками.
- Основную конфигурацию не грузить целиком — только частичная загрузка
  (инвариант пересборки: `.zcode/1c/contour.json` → `unica.rebuild_rules`).
- Служебные файлы выгрузки (`ConfigDumpInfo.xml`, `DumpFilesIndex.txt`, `.build/`) не коммитятся.
