# Контракт журнала проектных исключений

Файл: `.zcode/1c/standards-exceptions.yaml`, трекается git-ом проекта.

Назначение: единственный канал проектной специфики ревью. Навык не
содержит проектных фактов; всё, что проект решил отклонять от рекомендаций
по умолчанию, живёт здесь и нигде больше.

## Формат

```yaml
version: 1
exceptions:
  - id: <kebab-case, уникален в файле>
    diagnostic: <код диагностики unica.check, напр. DeprecatedPlatformApi>
    subject: "<что именно исключено: метод, вызов, идентификатор>"
    scope: all                    # all | node:<адрес узла unica> | file:<путь>
    standard: <std-id или краткое имя требования>
    rationale: >
      Основание решения: почему отклонение корректно для этого проекта
      и чем оно мотивировано (семантика, внешний контракт, наследие).
    decided: <YYYY-MM-DD>
    owner: <кто принял решение>
```

## Семантика

- Совпадение находки: `diagnostic` точно + `subject` точно
  (у одного кода диагностики могут быть разные subjects — например,
  deprecated у `ТекущаяДата` и у `Сообщить`) + `scope` покрывает узел.
- `waived` не исчезает из отчёта — выводится одной строкой с id и
  основанием. Видимость сохраняется, шум убирается.
- Исключение действует, пока запись в файле. Устаревшее (починили,
  изменилось решение) удаляет владелец; ревьюер может лишь предложить.
- Агент не пишет в журнал сам: готовит текст записи по принятому
  владельцем вердикту, файл меняется только по команде.
- Отсутствие файла легально: все находки по умолчанию живые.
- Записи без заполненного `rationale` и `owner` недействительны: ревьюер
  трактует их как отсутствие исключения и сообщает о некорректной записи.

## Границы агностичности

- В навыке нет ни одной ссылки на содержимое журналов конкретных проектов.
- Журнал покрывает только домен B (стандарты). Отклонения от требований
  стайл-пака журналом не оформляются: приоритет пака закреплён контуром,
  решение принимает владелец по находке.
- Исключение не может перекрывать класс `compile-risk` и вердикты `risk`:
  то, что не компилируется, журналом не лечится.
- Формат.version: при несовместимом изменении формата ревьюер останавливает
  сверку исключений и сообщает (fail-closed), не угадывая.
