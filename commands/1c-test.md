description: E2E-прогон 1С: workflow 1c-e2e-run с ЖР-сверкой и анти-ложно-зелёным вердиктом
---

Прогони e2e-сценарий через workflow (исполнение — кодом, вердикт не по
самочувствию модели):

1. Аргумент $ARGUMENTS разбери как `сценарий [профиль]`: путь к XML в
   `.zcode/testpilot/scenarios/` (пусто — все сценарии) и имя профиля из
   profiles.yaml (по умолчанию `main`).
2. Запусти workflow `1c-e2e-run` (CreateWorkflow, source saved/по имени из
   `.zcode/workflows/1c-e2e-run.dwf.ts`) с аргументами `scenario` и `profile`.
3. Итог доложи по его вердикту: `passed`/`failed`, число проверок, ошибки ЖР;
   отчёт-артефакт уже опубликован workflow.

Если workflows недоступны в этой сессии (вендоренный файл не подхвачен) —
скажи об этом явно и не подменяй ручным прогоном без ЖР-сверки: это и есть
тот ложный зелёный, которым контур не занимается.
