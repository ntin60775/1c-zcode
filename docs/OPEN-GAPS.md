## G2 — конвертация старого покрытия: доказана на одной фиче

- **Что есть:** канон в skills/1c-test-contour (фича = источник → один

  логика-тесты onec_db, пользовательские пути → GUI-e2e); workflow
  `1c-e2e-author`; живой кейс уровня D пилота (1 фича, конвертирована и
  удалена после зелёного прогона).
- **Чего нет:** доказательства масштабирования на весь объём старого
  покрытия. Прогресс на пилоте: из 2 фич архива конвертирована
  `СборДанныхКонтрагентов` (1 passed 14.52s, ЖР 0 Error, `git rm` фичи,
  коммит f172d67b9, sess_9524f03f); осталась `оплата-акт-отвеса` (GUI)
  и инварианты 14 yAxUnit-модулей (~4900 строк, карта переноса собрана
  агентом пилота). Из 9 сценариев ТиповойПотокПеревода перенесены 3.
- **Устранение (на пилоте, по директиве):** конвертировать остатки
  покрытия пилота: фичу `оплата-акт-отвеса` (GUI), инварианты расширения
  по карте. HTTP-сценарии 1–5 и контракт 8 отложены — нужен откат
  настроек интеграции, решение владельца.
- **Критерий закрытия:** в архиве пилота не осталось непокрытых фич; каждая
  либо конвертирована, либо осознанно помечена legacy с обоснованием;
  инварианты расширения перенесены (логика → onec_db, пути → GUI-e2e).

## G3 — bsl_style_gate: блокировка не проверена живым срабатыванием

- **Что есть:** HARD_BLOCK=True, фильтр изменённых строк, тесты 13/13.
  Живая сессия пилота (sess_9524f03f, 2026-10-03) вскрыла дефект глубже:
  **хуки вообще не исполнялись рантаймом ZCode** — wire_config писал
  `hooks.<Event>`, схема требует `hooks.events.<Event>` (аудит молчал с
  2026-10-01). Исправлено в v0.4.18 (bc7e732, пилот 2f64356fc); вручную
  синтетическими событиями гейты дают exit 2 с точными причинами
  ([tab-rhythm], строка/кол-во нарушений), чистая правка проходит тихо.
- **Чего нет:** живого срабатывания в раннере ZCode — сессия пилота
  стартовала до фикса; пруф даст следующая сессия (хуки читаются на старте).
- **Устранение:** в новой сессии пилота: правка `src/**/*.bsl` → отказ
  PreToolUse уника-гейта; вписать файл в `.zcode/unica-gate-escalations.txt`
  → Edit с TAB-нарушением → PostToolUse стайл-гейт блокирует (exit 2,
  причина в stderr) → исправить → проходит → эскалацию удалить.
- **Критерий закрытия:** зафиксированное живое срабатывание (exit 2) и
  разблокировка после исправления. Пробел «стиль unica-правок» —
  issue #10.

## Примечание: топология установки (не отклонение)

Плагин вендорит skills/hooks/workflows/scripts/templates в `.zcode/`
проекта, bootstrap пишет секцию AGENTS.md, `wire_config.py` подключает MCP
и хуки. Внешние зависимости ставятся не одним пакетом, а по топологии:
`1c-testpilot` — `scripts/install_testpilot.sh` (пин ==1.8.1), паки
`1c-bsl-code-style` и `1c-ssl-skills` — записями каталога
sot-zcode-marketplace. Наличие и живость всего набора проверяет
`/1c-doctor`. Это осознанная топология поставки, а не пробел.
